Optimisation et maintenance corrective d'une application multiplateforme

Description du projet

Ce projet a porté sur l'analyse, la correction et l'optimisation d'un système complexe de recherche de stage. Il s'agissait d'assurer la cohérence entre la plateforme web (Back-office Symfony) et l'application mobile (Android Studio).

Objectifs

  • Maintenance corrective : Identification et résolution de bugs critiques impactant l'expérience utilisateur.
  • Optimisation : Amélioration des performances des requêtes API entre le serveur Symfony et l'application Android.
  • Refactorisation : Nettoyage du code existant pour améliorer sa lisibilité et sa maintenabilité.

Techniques et outils

  • Web : Symfony .
  • Mobile : Android Studio .
  • Outils : Git (gestion de versions).

Organisation et rôle

Ce projet a été réalisé au sein d'une équipe de 5 étudiants.

Travail en groupe

Nous avons dû coordonner nos efforts pour maintenir une cohérence graphique et technique sur l'ensemble du site. La collaboration a été essentielle pour intégrer les différentes pages produites.

Travail individuel

  • Mettre en place le chemin API vers la Base de données sur la partie Android.
  • Optimisation de fonctionnalitées sur la partie Android.
  • Ecriture du rapport final.

Bilan du projet

Défis rencontrés

La principale difficulté a été de comprendre une base de code existante pour y apporter des modifications sans créer de régressions sur les fonctionnalités déjà opérationnelles.

Compétences acquises

  • Méthodologie de débogage et analyse de logs.
  • Maîtrise de l'intégration continue et des bonnes pratiques de développement.
  • Capacité à travailler sur des systèmes multiplateformes communicants via API REST.
