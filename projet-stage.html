Stage : Conception d'outils de gestion (Back-Offices)

Contexte

Stage réalisé au sein de l'agence Kalam Conseil. L'objectif était de moderniser les outils de gestion de l'agence et de ses clients par la création de back-offices sur-mesure.

Objectifs

  • Back-Office Kalam Conseil : Création d'un outil interne pour centraliser la gestion des ressources de l'agence (Clients, Actualités, Réalisations).
  • Back-Office QJMOTOR : Développement d'une interface de gestion dédiée aux besoins spécifiques de ce client (Typologie de véhicules, inventaire, actualités).
  • Développement Full-Stack : Conception des bases de données (MySQL) et développement des interfaces web (Frontend) permettant l'affichage et la manipulation dynamique des données.

Techniques et outils

  • Backend : PHP / Laravel
  • Base de données : MySQL.
  • Frontend : Blade/CSS/JS.

Organisation et rôle

Ce projet a été réalisé individuellement.

Travail individuel

  • Conception des maquettes graphiques.
  • Conception des pages web via les maquettes réalisées.
  • Conception des bases de données.
  • Développement des fonctionnalités.

Bilan du projet

Défis techniques

Le principal défi fut de concevoir des bases de données relationnelles , capables de s'adapter aux besoins très différents de l'agence et de son client automobile.

Compétences acquises

  • Application concrète des méthodes de travail.
  • Maîtrise de la liaison entre une interface utilisateur (Back-Office) et une base de données complexe.
  • Gestion de projet client en autonomie.
